Azure Policy & Governance Lab

Hands-on Azure Policy and Governance lab implemented using Microsoft Azure, focusing on enterprise governance, compliance, resource standardization, access control, monitoring, networking and cost management.

🎯 Objectives
Design an enterprise-style Azure Management Group hierarchy
Implement Azure Policy for governance and compliance
Configure policy assignments and validate compliance
Implement Azure RBAC and least-privilege access
Standardize Resource Groups, naming conventions and resource tags
Configure Azure Monitor, Activity Logs, Diagnostic Settings and Log Analytics
Implement network governance using Virtual Networks and Network Security Groups
Monitor Azure consumption using Cost Management
